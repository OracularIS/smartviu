# Version 2026.1.3.6 – Code Block Support & Action Context

## Release Notes

- **Code Block Support in Command Syntax** – The input section of a command can now be a `{ }` code block, so input fields can be built with multi-step logic.
- **Action Context Values** – Actions now receive the report's filter values and the selected row's values, so the action form can prefill and use them.
- **Security Fixes** – Strengthened report list filtering, email export attachments and export file handling against unsafe input.
- **Order Report Fixes** – Corrected report group names and authorization, and the **Bill to Address** hyperlink now shows a readable label.
- **General Bug Fixes** – Minor fixes and code cleanup.
