# Version 2026.1.3.3 – Command Maintenance Rename & Detail Grid Fixes

## Release Notes

- **Naming Convention Update** – Renamed Command Maintenance to the new naming convention.
- **Find Hint Fix** – Resolved the **Find** hint reappearing while an auto-run report was loading.
- **Detail Grid Filter Fix** – Filter bar and grid now stay visible when a filter returns no data.
- **Detail Grid Error Fix** – Resolved an error when changing rows with a filter applied.
- **Detail Grid Loading Fix** – Resolved the detail grid sometimes not loading on row selection.
- **Detail Grid Pagination Fix** – Page size and total record count now work correctly.
